# تثبيت Arcadia في صالة (خطوة بخطوة)

> **حالة هذا الدليل:** الـ installers وسكربتات الإعداد مكتوبة، لكن **لم يُجرَّب التثبيت على أجهزة Windows حقيقية بعد**. جرّب أول مرة على جهازين غير مهمّين (كاشير + جهاز ألعاب واحد) قبل أي صالة حقيقية. تشغيل الـ agent **يقفل الجهاز** بملء الشاشة.

## ما الذي ستثبّته

| الحزمة | أين | عدد المرات |
|---|---|---|
| `ArcadiaHallServer.msi` | جهاز الكاشير (يبقى شغّالاً) | مرة واحدة لكل صالة |
| `ArcadiaAgent.msi` | **كل** جهاز ألعاب | مرة لكل جهاز |

لا يلزم تثبيت أي برنامج آخر (الـ runtime مضمّن).

## تجهيز (من لوحة التحكم، بحساب المالك)

1. أضف أجهزة الألعاب في **الأجهزة** (نوعها PC) إن لم تكن مضافة.
2. افتح **الوكلاء (Agents)** ← قسم **«ربط الأجهزة بهذه الصالة»**. من هنا تنشئ أكواد الربط.
   - الكود **يعمل مرة واحدة ويصلح 10 دقائق**. أنشئه قبل الاستعمال مباشرة. الكود الجديد يلغي القديم.

## 1) جهاز الكاشير (مرة واحدة)

1. ثبّت `ArcadiaHallServer.msi` (يحتاج صلاحية مدير).
2. من لوحة التحكم أنشئ كود **«خادم الصالة»**.
3. شغّل **Arcadia Hall Server setup** من قائمة Start (تلقائياً كمدير)، أو:
   ```powershell
   powershell -ExecutionPolicy Bypass -File "C:\Program Files\Arcadia\HallServer\Setup-HallServer.ps1"
   ```
   أدخل عنوان الـ cloud (إن لم يكن مضمّناً) والكود. السكربت يربط الخادم بالسحابة ويشغّل الخدمة ثم يطبع:
   - **CA fingerprint**: بصمة طويلة (64 حرفاً). **سجّلها**، تحتاجها لكل جهاز.
   - **عنوان الخادم**: مثل `https://192.168.1.10:7421`. استعمل عنواناً ثابتاً (احجز IP للكاشير في الراوتر).
4. لاحقاً يمكنك إعادة عرضهما بـ:
   ```powershell
   & "C:\Program Files\Arcadia\HallServer\Arcadia.HallServer.exe" info
   ```
5. المنفذ **7421** مفتوح تلقائياً للشبكة المحلية فقط. تأكد أن أجهزة الألعاب في نفس الشبكة.

## 2) كل جهاز ألعاب

1. ثبّت `ArcadiaAgent.msi`.
2. من لوحة التحكم: اختر **الجهاز** ثم **إنشاء كود** (يظهر الكود و**معرّف الجهاز**).
3. شغّل **Arcadia Agent setup** من قائمة Start، أو:
   ```powershell
   powershell -ExecutionPolicy Bypass -File "C:\Program Files\Arcadia\Agent\Setup-Agent.ps1" -PlayerUser Player -TechnicianPin 4821
   ```
   سيسألك عن: عنوان الخادم، بصمة الـ CA، الكود، معرّف الجهاز، اسم الصالة والجهاز.
   - `-PlayerUser`: حساب Windows الذي يلعب به الزبائن (يقيّد من يستطيع التحدث مع شاشة القفل). موصى به.
   - `-TechnicianPin`: رمز للفتح الطارئ (اختر رمزك الخاص). يُخزَّن كـ hash فقط.
4. السكربت يربط الجهاز ثم **يسألك** قبل تشغيل الخدمة. عند التشغيل يظهر القفل. ابدأ جلسة من لوحة التحكم ليفتح.
5. افتح الفني الطارئ على شاشة القفل بـ `Ctrl+Shift+F12` ثم الـ PIN.

## متى يُطلب كود جديد؟

- **الربط الأول فقط** لكل جهاز ولخادم الصالة.
- مرة جديدة عند: استبدال الجهاز أو إعادة تثبيت Windows، أو **استبدال جهاز الكاشير** (يتغير الـ CA فيُعاد ربط كل أجهزة الألعاب)، أو بعد **سنة** (الشهادة صالحة سنة ولا يوجد تجديد تلقائي بعد).

## لوحة التحكم

- **الوكلاء**: حالة كل جهاز (متصل/غير متصل، النسخة، آخر اتصال).
- **خوادم الصالة**: حالة خادم الكاشير، وزر **إلغاء الربط** (يوقف وصول الأوامر فوراً، وتبقى الجلسات الجارية على الأجهزة).

## مشاكل شائعة

| العرض | السبب والحل |
|---|---|
| `Pairing refused` عند الربط | الكود مستعمل أو انتهى. أنشئ كوداً جديداً. |
| `CA fingerprint does not match` | البصمة خاطئة أو العنوان لخادم آخر. انسخها من `info`. **لا تتجاوز هذا الخطأ.** |
| الجهاز لا يتصل بعد الربط | جدار حماية/شبكة. من الجهاز: `Test-NetConnection <عنوان الكاشير> -Port 7421`. |
| بعد الربط ظهر قفل ولا تفتح الجلسات | الخادم غير متصل بالسحابة (راجع **خوادم الصالة**) أو الجهاز غير مربوط بمعرّف صحيح. |
| الخدمة لا تعمل | Event Viewer ← Windows Logs ← Application، المصدر `ArcadiaAgent` / `ArcadiaHallServer`. |

## إلغاء التثبيت

`appwiz.cpl` ← احذف Arcadia Agent / Arcadia Hall Server. تبقى بيانات الربط في `C:\ProgramData\Arcadia` (احذفها يدوياً لإعادة الربط من الصفر).

## حدود معروفة (MVP)

- لا يوجد وضع عمل بلا إنترنت (جلسات جديدة بدون سحابة)، ولا فك ربط جهاز واحد من لوحة التحكم، ولا تجديد تلقائي للشهادات.
- شاشة القفل **ليست حاجزاً أمنياً**: يجب أن يلعب الزبائن بحساب Windows عادي (غير مدير) مع قيود سياسات يطبّقها فني يدوياً.
- لم تُجرَّب مع ألعاب ومكافحات غش حقيقية بعد.
